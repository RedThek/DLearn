# Gabarit d'auteur de contenu — Liteschreib IKII

Ce gabarit standardise la création d'une unité de contenu pédagogique, afin de produire efficacement le volume nécessaire à la couverture large de niveaux GeR retenue en MVP (ADR-008). Toute nouvelle unité doit suivre cette structure avant intégration dans la cartographie (`09-cartographie-contenu-pedagogique.md`) puis dans la base Room (Mission A4).

| Champ | Valeur |

## 3. Exercices de compréhension

### Exercice 1 — Type : `QCM` / `Texte à trous` / `Vrai-Faux` *(choisir un type)*

```
Consigne : ...

Options (si QCM) :
[ ] Option A
[ ] Option B
[ ] Option C
[ ] Option D  ← cocher la bonne réponse ici

Réponse attendue (si texte à trous ou vrai/faux) : ...
```

> Recommandation minimale par unité : 3 à 5 exercices de compréhension pour un niveau A1/A2, éventuellement davantage pour B1/B2.

## 4. Exercice d'écriture (module Écriture)

```
Consigne d'écriture liée à l'œuvre : ...

Longueur attendue (à titre indicatif, non bloquant) : ... mots

Grille d'auto-évaluation simplifiée (FR-17) :
- Longueur respectée : oui / non
- Cohérence avec la consigne : oui / non
- Vocabulaire du niveau GeR utilisé : oui / non
```

## 5. Repères de calibrage par niveau GeR (aide-mémoire auteur)

| Niveau | Longueur de texte indicative | Complexité grammaticale attendue | Longueur de production écrite attendue |
|---|---|---|---|
| A1 | 50–100 mots | Présent, phrases simples | 20–40 mots |
| A2 | 100–200 mots | Passé composé/Perfekt, connecteurs simples | 40–80 mots |
| B1 | 200–350 mots | Subordonnées, temps variés | 80–150 mots |
| B2 | 350–500 mots | Structures complexes, nuances | 150–250 mots |

> Ces repères sont indicatifs et doivent être ajustés/validés avec l'encadrant académique au regard du CECR et du curriculum *Ihr und Wir Plus* réel.

## 6. Checklist avant intégration d'une unité

- [ ] Fiche d'identité complète (section 1)
- [ ] Statut des droits vérifié et documenté (ADR-006)
- [ ] Glossaire renseigné (section 2)
- [ ] Exercices de compréhension rédigés avec corrections (section 3)
- [ ] Exercice d'écriture rédigé avec grille d'auto-évaluation (section 4)
- [ ] Relecture par un locuteur natif ou l'encadrant académique (recommandé, surtout au-delà du niveau A1)
- [ ] Unité ajoutée à la cartographie de contenu (`09-cartographie-contenu-pedagogique.md`) avec statut `Validé`
- [ ] Numéro de version de contenu attribué (`14-charte-versionnage-contenu.md`)
