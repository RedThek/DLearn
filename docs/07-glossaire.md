# Glossaire — Liteschreib IKII

## Termes didactiques / recherche en didactique des langues

| Terme | Définition |
|---|---|
| **DaF** (*Deutsch als Fremdsprache*) | Allemand langue étrangère — champ didactique dans lequel s'inscrit le projet |
| **GeR / CECR** | Gemeinsamer europäischer Referenzrahmen / Cadre européen commun de référence pour les langues — échelle de niveaux (A1 à C2) utilisée pour situer les contenus et la progression |
| **MALL** | *Mobile-Assisted Language Learning* — apprentissage des langues assisté par le mobile |
| **CALL** | *Computer-Assisted Language Learning* — apprentissage des langues assisté par ordinateur |
| **ICALL** | *Intelligent Computer-Assisted Language Learning* — CALL intégrant des composantes IA |
| **DigCompEdu** | Cadre européen de référence des compétences numériques des enseignants |
| **ASR** | *Automatic Speech Recognition* — reconnaissance automatique de la parole (Phase 3, différée) |
| **AWE** | *Automated Writing Evaluation* — évaluation automatique de l'écrit (Phase 3, différée) |
| **ITS** | *Intelligent Tutoring System* — système de tutorat intelligent (Phase 3, différée) |
| **FSRS** | *Free Spaced Repetition Scheduler* — algorithme de planification de la répétition espacée, référence pour la planification des révisions (module Suivi) |
| **DBR** | *Design-Based Research* — méthodologie de recherche itérative combinant conception et évaluation en contexte réel |

## Termes techniques (Android / ingénierie)

| Terme | Définition |
|---|---|
| **BYOD** | *Bring Your Own Device* — les élèves/enseignants utilisent leurs propres appareils, hétérogènes en performance |
| **Offline-first** | Principe de conception où l'application fonctionne intégralement sans connexion réseau |
| **Clean Architecture** | Architecture logicielle en couches (domain/data/presentation) avec inversion de dépendance |
| **MVVM** | *Model-View-ViewModel* — patron de conception séparant état/logique de présentation (ViewModel) et UI (View/Composable) |
| **Hilt** | Framework d'injection de dépendances pour Android, basé sur Dagger |
| **Room** | Bibliothèque de persistance Android au-dessus de SQLite |
| **Flow** | Type Kotlin pour les flux de données asynchrones réactifs, utilisé avec Room pour observer les changements de données |
| **KSP** | *Kotlin Symbol Processing* — processeur d'annotations plus performant que kapt, utilisé pour Room/Hilt |
| **Jetpack Compose** | Toolkit déclaratif de construction d'UI Android |
| **Navigation Compose** | Bibliothèque de navigation entre écrans Compose |
| **Material Design 3 (MD3)** | Système de design de Google utilisé comme base du design system de l'application |
| **TFLite** (TensorFlow Lite) | Framework d'inférence de modèles de machine learning embarqués sur mobile |
| **Gemini Nano** | Modèle de langage compact conçu pour l'exécution on-device sur certains appareils Android |
| **TTS** | *Text-to-Speech* — synthèse vocale, ici via l'Android TTS API pour la lecture audio des textes |
| **ML Kit (OCR)** | Kit Google de vision par ordinateur, notamment reconnaissance de texte (OCR), envisagé en Phase 3 |
| **ADR** | *Architecture Decision Record* — document court figeant une décision d'architecture, son contexte et ses conséquences |
| **Definition of Done (DoD)** | Ensemble de critères vérifiables qu'une tâche doit satisfaire pour être considérée terminée |
| **Definition of Ready (DoR)** | Ensemble de critères qu'une tâche doit satisfaire avant de pouvoir être démarrée |
